# Mokka Decisions

An open-source project for small, local decision models: choose among defined options, return probabilities, and abstain when confidence is insufficient.

**Status:** initial project scaffold. No implementation, trained weights, or benchmark results are available yet.

The planned first release targets English, German, and Spanish, with reproducible training and evaluation.
